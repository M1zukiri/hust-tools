# NCM 音乐转换器

把网易云音乐下载的 `.ncm` 加密文件转换为标准的 **MP3 / FLAC**，可在任意播放器中播放。

纯 Python 实现，**零第三方依赖**，Python 3.6+ 即可运行。

## 使用方法（三选一）

### 1. 图形界面（推荐）

双击运行 `ncm2music.py`（或命令行不带参数运行）：

```
python ncm2music.py
```

- **直接把 `.ncm` 文件或整个文件夹拖进窗口**即可添加（文件夹会递归扫描所有子目录）
- 也可以点击 **添加文件** / **添加文件夹** 按钮选择
- 点击 **输出目录…** 选择保存位置；不选则默认保存到源文件同目录
- 点击 **开始转换**

### 2. 命令行

```
python ncm2music.py 歌曲1.ncm 歌曲2.ncm ...
python ncm2music.py D:\音乐\下载目录          # 整个文件夹递归转换
python ncm2music.py D:\音乐\下载目录 -o D:\输出目录
```

### 3. 拖拽

把 `.ncm` 文件直接拖到 `ncm2music.py` 图标上即可转换（输出到源文件同目录）。

## 说明

- 转换是无损的：程序只做解密，不重新编码，音质与源文件完全一致。
- 输出文件名自动取为 `艺术家 - 歌名.扩展名`（来自文件内嵌的元数据）。
- 输出文件不带内嵌标签和封面，如需补全标签可用 [MusicTag](https://www.cnblogs.com/vinlxc/p/11347744.html)、Mp3tag 等工具一键刮削。

## 常见问题

- **提示“不是有效的 ncm 文件”**：确认文件确实是网易云客户端下载的 `.ncm`，而非其他格式改名。
- **闪退**：如果双击闪退，请在命令行中运行查看报错信息。

## 已知限制

- 文件中的 CRC32 校验位计算方式未公开，本工具不校验。因此**音频区被截断/污染的 ncm 仍会“成功”转换**，产出同样残缺的音频（源数据本身已不完整）。头部损坏、长度字段越界、封面篡改等结构性问题会被检测并报错。
- 不识别 m4a/wav/ogg 以外的冷门封装；内容嗅探失败时按元数据 `format` 或 `.mp3` 命名。
